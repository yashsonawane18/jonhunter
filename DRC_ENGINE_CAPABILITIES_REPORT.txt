6. DISCOVERY CHANNELS & MULTI-TIER DATA REPOSITORIES
================================================================================
JonHunter employs a multi-tiered fallback architecture to ensure 100% search uptime 
even during internet network disruptions or third-party ATS maintenance windows.

Data Ingestion & Storage Hierarchy:
  Level 1: Fast In-Memory RAM Cache (Engine Cache Warmer)
    - Holds 8,500 to 11,200+ parsed jobs directly in memory.
    - Query Latency: ~10ms.
    - Tokenized inverse-index keyword lookup with word-boundary matchers.

  Level 2: Persistent SQLite WAL Database (job_engine/data/drc_job_discovery.db)
    - Table: `discovered_jobs` (Indexed on job_id, title, company, location, source).
    - Current Active Verified Jobs in Storage: 1,787 Requisitions across 791 Employers.
    - Source Breakdown in Database:
        * Direct ATS Greenhouse: 415 verified jobs
        * Direct ATS Lever: 81 verified jobs
        * Direct ATS Ashby: 53 verified jobs
        * Direct ATS General/Enterprise: 10 verified jobs
        * LinkedIn Active Verified Live Stream: 1,219 verified jobs
        * Curated Verified Requisitions: 9 verified jobs
    - Auto-Save Pipeline: Every newly crawled requisition from live searches is 
      automatically persisted to SQLite with conflict resolution (`INSERT OR REPLACE`).

  Level 3: Client-Side Offline Verified Archive (JonHunter UI Fallback)
    - Embedded verified requisitions packaged inside the web client.
    - Guarantees zero "Search Failed" blank screens even when offline.

10. DEDUPLICATION, DATA INTEGRITY & ZERO-COST ARCHITECTURAL DESIGN
================================================================================

A. Deterministic Deduplication:
  Every requisition is normalized using canonical title cleanup, lowercase employer 
  slugging, and SHA-256 fingerprint hashing over `[company_slug + normalized_title + location]`. 
  This guarantees:
    - Zero duplicate listings across repeated crawl cycles.
    - Seamless reconciliation between direct ATS postings and LinkedIn feeds.
    - Stale job pruning when requisitions close on official career pages.

B. Zero-Cost Architectural Blueprint:
  Unlike commercial competitors that spend thousands of dollars monthly on paid API keys:
    - Zero LLM API billing for search queries (100% deterministic lexical + tokenized matching).
    - Zero paid scraping proxies required (direct official ATS endpoints respect standard HTTP 
      user agents without triggering Cloudflare challenges).
    - Lightweight server footprint (can run continuously on a free 512MB RAM cloud tier or 
      locally as a lightweight developer daemon).
